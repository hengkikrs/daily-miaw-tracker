## 2. DESIGN TOKENS  [STATIC]

Blok token yang terdefinisi:

| File | Blok | Jumlah |
|---|---|---|
| `styles.css` | `:root` | 30 |
| `styles.css` | `[data-theme="dark"]` | 24 |
| `theme.css` | `:root` | 85 |
| `theme.css` | `[data-theme="dark"]` | 82 |

- **[VERIFIED] 30 token didefinisikan di DUA file** (`--bg`, `--text`, `--muted`, `--line`, `--teal`, `--green`, `--blue`, `--violet`, `--pink`, `--rose`, `--orange`, `--amber`, `--cyan`, `--lime`, `--danger`, `--panel*`, `--sidebar*`, `--shadow`, `--sec-*`, `--focus`, `--radius`). Nilai di `styles.css` adalah **palet lama (cool)** yang sudah mati karena `theme.css` dimuat terakhir. Risiko: pembaca CSS/anggota tim baru akan menganggap `styles.css :root` sebagai sumber kebenaran → drift. **Rekomendasi:** hapus blok `:root`/dark dari `styles.css`, sisakan satu sumber (`theme.css`).
- **[STATIC] 7 token dipakai tanpa definisi:** `--cc, --gc, --jc, --pc, --sec, --tc, --tone`. Lima di antaranya (`--tc/--cc/--pc/--gc/--jc`) **diset inline dari JS** (pola benar). `--sec` & `--tone` tidak pernah diset → selalu memakai fallback (`var(--sec, var(--teal))`) = indireksi mati.
- **[STATIC] Token dari JS** (bukan mati): `--chart-*` (2 pakai), `--cat-*` (9), `--st-*` (5), `--jv-*` (8).

## 3. KONTRAṢ WCAG AA  [VERIFIED]

Diukur pada 16 view (light mode, data terisi). Ambang: **4,5:1** teks normal, **3:1** teks besar (≥24px atau ≥18,66px bold). Total **264 elemen di bawah ambang**, 46 pola unik.

### 3.1 Tekst nyaris tak terbaca — token BORDER dipakai sebagai warna TEKS  🔴 P1

| Nilai warna | Token | Rasio | Lokasi |
|---|---|---|---|
| `#E2E8F0` | `--line` | **1,23:1** | MiawAI — teks saran "Cara pakai Goals & Project" |
| `#CBD5E1` | `--line-strong` | **1,48:1** | Catatan "Diperbarui 2 jam lalu"; Dokumen label "Berkas", "Project"; placeholder editor catatan; `.doc-dim` |

15 aturan memakai `color: var(--line-strong)` (`.note-card-time`, `.note-cat`, `.note-tpl-arrow`, `.note-editor::before`, `.doc-type`, `.doc-cat`, `.doc-dim`, …).

**Perbandingan historis [VERIFIED]:** sebelum redesign `--line-strong: #cfc2ac` (1,72:1) — **sudah gagal juga**, redesign memperburuk sedikit (1,48:1). Jadi ini bug lama, bukan regresi baru.

**Rekomendasi:** ganti 15 aturan itu ke `var(--muted)`; simpan `--line*` khusus border.

### 3.2 Teks sekunder `--muted` gagal AA  🔴 P1 (regresi dari redesign)

| Latar | Rasio | Contoh |
|---|---|---|
| `#FFFFFF` (panel) | **4,48:1** | label, meta, kicker |
| `#F1F5F9` (panel-soft) | **4,34:1** | chip, tab, label kartu ("↑ Masuk", "Arsip", "Kebiasaan", "Project") |

**Perbandingan historis [VERIFIED]:** `--muted` lama (tema hangat) = `#776b5e` → **4,84:1 (LULUS)**; setelah redesign = `#64748B` → **4,34–4,48 (GAGAL)**. Penyebab: mengadopsi `--color-text-secondary: #64748B` dari brief secara harfiah.

**Rekomendasi:** `--muted: #475569` (slate-600) → 7,0:1 di atas putih ✓; dark mode `#94A3B8` (sudah 4,7:1 di `#111827`, aman).

### 3.3 Tombol primer gagal AA  🔴 P1

| Latar | Teks | Rasio | Contoh |
|---|---|---|---|
| `#16A34A` (`--teal`) | putih | **3,30:1** | "+ Tambah Goal", "Tambah Kebiasaan", "+ Tambah Data", "+ Tambah Budget", "Mulai gratis" (landing) |
| `#22C55E` (green-500) | putih | **2,28:1** | kalender: tanggal "17"; chip "Semua" |
| `#22C55E` | sebagai teks | **2,18:1** | Goals: heading "Jangka Pendek" |
| `#D97706` (amber-600) | sebagai teks | **3,04:1** | Goals: "Jangka Menengah" |

**Rekomendasi:** tombol pakai `--teal-strong` (`#15803D`) → putih = **4,87:1 ✓**; green-500 hanya untuk elemen dekoratif (bar/dot), bukan teks atau latar berteks putih; amber teks → `#B45309` (4,6:1 ✓).

## 6. RESPONSIF  [VERIFIED]

17 view × 8 lebar (320·360·390·414·480·600·768·1024) = 136 kombinasi.

- **0 overflow horizontal halaman** di seluruh kombinasi ✓ (sangat baik)
- 🔴 **P2 — Kalender terpotong pada ≤ 375px.** `.jadwal-grid` butuh lebar minimum ~334px sedangkan wadahnya 262px (320px) / ~317px (375px); `#content` punya `overflow-x: hidden` → **isi kalender dipotong, tidak bisa di-scroll**. Terukur: KLIP di 320/360/375, normal ≥ 390. **Fix:** `grid-template-columns: repeat(7, minmax(0,1fr))` + kecilkan padding/ukuran angka sel di ≤ 380px, atau beri `.jadwal-grid-wrap { overflow-x: auto }`.
- 🟡 **P3 — `.pt-group-title`/`.pt-group-sub` (Project Task) terpotong di 320px** (butuh 43–58px, tersedia 37px): kolom judul grup terlalu sempit.
- 🟡 **P3 — `.task-check` meluber 6–11px** dari wadahnya di semua view Task (border/shadow lingkaran centang).

**Perbaikan tambahan yang ditemukan saat mengerjakan P1:**
- **Bug CSS**: `color-mix(in srgb, var(--sidebar-text) 0.78, transparent)` — sintaks salah (harus `78%`) → deklarasi tidak valid; diperbaiki.
